
# Portable Trilateration Radar

ESP32 + 3x HLK-LD2410B radar modules, trilateration math gives live XY position, shown on TFT screen. Battery powered, portable.

## where its at
Simulated logic in Wokwi (pots standing in for radar sensors). Real hardware is the next step

## Parts
- ESP32 devkit
- 3x HLK-LD2410B
- ILI9341 TFT
- 18650 battery + TP4056
